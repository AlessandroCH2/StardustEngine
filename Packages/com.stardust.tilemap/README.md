# 2D Tilemap

Grid-based 2D levels for Stardust: tilesets, a Tilemap stored in a Sprite Batch, a Tile Palette, Scene view tools (paint, erase, box, fill, pick) with single, stamp, random and auto-tile brushes, animated tiles and 2D colliders.

- `Scripts/` — runtime: `Tilemap`, `Tileset` (namespace `Stardust.Tilemaps`).
- `Editor/` — Tilemap inspector, Scene view tools and the Tile Palette window.
- `Samples/` — `Tiles.png` (8 x 6 pixel-art tiles: animated water, coins and lava, an auto-tile path) and `Tiles.tileset`.

Install it from **File → Project Settings → Packages → Stardust Packages → Install**. Full guide: `docs/TILEMAP.md` in the engine repository.
